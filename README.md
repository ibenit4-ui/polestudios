# POLE Studios

Catálogo online de POLE Studios. Sudaderas y prendas de manga larga.
Web de solo consulta: no hay carrito ni pago online, los pedidos se hacen por DM.

**En producción:** [polestudios.es](https://polestudios.es)

## Qué hay aquí

```
index.html      La web entera (HTML + CSS + JS en un solo archivo)
assets/         Logo, vídeo de portada, fotos de las prendas, favicon
vercel.json     Cachea las imágenes y el vídeo para que cargue más rápido
LEEME.md        Guía de despliegue y de cómo cambiar cosas
```

No hay que compilar nada ni instalar dependencias: es HTML estático.
Para verlo en local, abre `index.html` en el navegador.

## Cómo se publica

Conectado a Vercel. Cada cambio que se sube a `main` se publica solo.

## Cómo cambiar cosas

Está todo en `index.html`:

- **Cinta de arriba** — busca `Pedidos DM` / `New clothes soon`
- **WhatsApp** — busca `wa.me/34688825797`
- **Popup de entrada** — busca `Are you ready?`
- **Las prendas** — la lista `var PRODUCTS = [` cerca del final

Hay más detalle en `LEEME.md`.
